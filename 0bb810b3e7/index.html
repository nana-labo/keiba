総合評価の内訳とは（クリックで展開）

ひと言で: 印（◎○▲△☆）を直感や文章判断ではなく、7 つの観点ごとに 0〜5 点で採点し、点数の順位から印を機械的に決める仕組み。同じ情報を入れれば誰がやっても同じ点数になる＝再現性が高い。

軸の補足説明:
状態 = 追い切り評価が中心。1週前・最終追切の動き／時計、馬体重推移、当日パドック気配、陣営コメントを含む総合的なコンディション。
血統 = 父・母父の距離・馬場・コース適性。実績の薄い馬（未勝利・新馬・初コース）ほど重み大。
ローテ = 前走からの間隔・休養明け・連戦疲労の評価。
前走補正 = 前走の結果（特に敗戦）をどれだけ「事故」として割引いて評価すべきか。不利・進路皆無・落鉄・極端ペース被害など。「度外視できる材料があるほど高得点」。

計算ロジック:

加重合計 = Σ(採点 × weight) / Σ(採点した軸の weight) ← 加重平均
  weight (G1): 近走0.20 / クラス0.15 / コース距離0.15 / 状態0.13 / 騎手0.08 / 馬場0.08 / 枠展開0.06 / 血統0.08 / ローテ0.05 / 度外視0.02
  weight (平場): 血統 0.10、状態 0.10 等で再配分
  weight (未勝利・新馬): 血統 0.25・状態 0.18・騎手 0.13 で再配分
↓ 補正（adjustments）を加算（補正履歴・evidence_ids 必須 = 隠れ補正禁止）
補正後 = 加重合計 + Σ(補正の差分)
情報量 = 軸ごとに集められた情報量（追切評価が複数あるか、過去走の本数、騎手データの蓄積など）の平均
  0/5＝そもそも採点できる材料がない 〜 5/5＝一次情報まで揃って確信を持って採点できる
↓
総合スコア = 補正後 × (情報量 / 5) ← 印選定に使う最終値
  同じ採点でも、材料が乏しい馬は控えめ評価になる仕組み（過信防止）

印付き馬の振り返り

◎ ペリエール2着 / 好走

前年のエルムS覇者で札幌ダ1700は2戦2勝。近走不振は近走の内容の軸で減点しつつ、コース実績・馬場適性・連覇プレミアム(R12)を軸に本命へ据えた判断が、1馬身半差の2着という結果でほぼ機能した。プロ予想家(Winsight田原基成氏)も同じ「リピーター」ロジックで本命に選んでおり、独立した視点からの評価一致もあった。

◯ ウェイワードアクト8着 / 大敗

1番人気だったが自ら逃げて直線で失速。事前スコアカードの仕上がりの軸には「調教師がバランス調整の難しさに言及」との注記が既にあった。騎手の軸も札幌ダ1700での相性の悪さ(複勝率0%)から、信頼度1点と低く評価していた。レース後の舟山瑠泉騎手のコメント「調整が難しくて、うまくできませんでした。バランス面とかが悪くなっていました」は事前の懸念と一致しており、◎にせず◯止まりにした判断は結果的に正しかった。

今回の学び

進行段階未更新でR39ゲート不発品質ゲートのR39系チェック(上位人気馬が採点対象外未採点のまま残っていないか)は進行段階が「枠順確定」「発走前」「事実修正済み」のときだけ動く。本レースは枠順・オッズが確定していたのに進行段階が「最終追い切り」のまま最後まで更新されず、ゲートが一度も走らないまま3番人気ルクソールカフェが無印優勝した。運用反映の抜けを機械チェックで検知できなかった構造的な穴。
芝→ダート復帰馬の巻き返しを評価軸が拾えない横断レビューの枠組みは前走が90日超前(休養明け警告)の馬にのみ適用され、直近走が新しくても芝⇄ダートのサーフェス変更で評価を下げるケースは対象外。ルクソールカフェは前走が芝(安田記念11着)だったが、この仕組みでは拾えなかった。
◎○▲の相対順位は機能・買い目配分が拾えず◎ペリエール2着・▲ヴァルツァーシャル5着と印の相対評価自体は的中に近かったが、馬連・ワイドの相手に無印3番を含めていなかったため全券種不的中。相手選定を無印上位人気馬まで広げる余地があった。
