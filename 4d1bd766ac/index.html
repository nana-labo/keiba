買い目（馬名付き）

先頭を奪い合いそうな馬（人気を見ずに並べた表）

スタート直後に先頭へ行きたがる馬を、出走全頭ぶん並べた表です。過去のレースで最初のカーブをどのあたりで回ってきたか、その実績だけで順番を決めています。人気・オッズ・この予想の印は一切使っていません。「誰が先頭を取るか」を当てる表ではなく、先頭を奪い合う顔ぶれを見落とさないための表です。上位の馬が多いほど、序盤から競り合ってペースが速くなりやすく、逆に上位が1頭だけなら楽に逃げてそのまま粘る展開になりやすい、という読み方をします。

計算ロジック:

加重合計 = Σ(採点 × weight) / Σ(採点した軸の weight) ← 加重平均
  weight (G1): 近走0.20 / クラス0.15 / コース距離0.15 / 状態0.13 / 騎手0.08 / 馬場0.08 / 枠展開0.06 / 血統0.08 / ローテ0.05 / 度外視0.02
  weight (平場): 血統 0.10、状態 0.10 等で再配分
  weight (未勝利・新馬): 血統 0.25・状態 0.18・騎手 0.13 で再配分
↓ 補正（adjustments）を加算（補正履歴・evidence_ids 必須 = 隠れ補正禁止）
補正後 = 加重合計 + Σ(補正の差分)
情報量 = 軸ごとに集められた情報量（追切評価が複数あるか、過去走の本数、騎手データの蓄積など）の平均
  0/5＝そもそも採点できる材料がない 〜 5/5＝一次情報まで揃って確信を持って採点できる
↓
総合スコア = 補正後 × (情報量 / 5) ← 印選定に使う最終値
  同じ採点でも、材料が乏しい馬は控えめ評価になる仕組み（過信防止）

今回の学び

『逃げ馬が多いから競り合う』は成立しないことがある逃げ脚質5頭を根拠に『競り合ってハイペース→差し有利』と読んだが、実際には⑤が単騎で行き、他の4頭は誰も競りかけなかった。2歳戦は各馬の主張が弱く、内枠かつ勝ち時計の速い1頭が難なく主導権を握るケースが多い。逃げ馬の頭数だけでペースを決めず、『テン3F実績が最速の馬 × 内枠 × 逃げ切り経験』の3点が揃う馬がいれば単騎濃厚と判定するロジックを入れたい。同日の盛岡・クラスターカップでも隊形読みを外しており、本日の共通の敗因である。
tags_weakに書いた致命的な懸念は、印の位置に反映する◎ルースアグレッシブのtags_weakには『逃げ馬が5頭おり主導権を握れるとは限らない』と明記していた。この馬の勝ちパターンは浦和2戦とも『1-1-1-1』の完全逃げ切りのみで、懸念が実現した瞬間に強みが丸ごと消える構造だった。『強みの成立条件＝懸念そのもの』という関係にある馬は、本命ではなく単穴以下へ落とす、あるいは条件付き本命として明示する扱いにすべきだった。CBC賞の振り返りで挙げた『懸念を書きながら印に反映しないギャップ』の再発である。
◎軸固定でない券種構成なら拾えた配当がある馬連⑤-⑦は2,040円（9番人気）で、▲と△の組み合わせ。印付け馬どうしを横並びに買う構成（印馬BOX・▲◯△の総流し）を標準の選択肢として併記していれば的中していた。bet_plansが空のまま公開されていた点も含め、『印は出すが買い目は出さない』状態が振り返りの精度を落としている。最低でも◎軸・印馬BOXの2案を併記する運用に戻したい。
