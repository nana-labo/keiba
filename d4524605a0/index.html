軸の補足説明:
状態 = 追い切り評価が中心。1週前・最終追切の動き／時計、馬体重推移、当日パドック気配、陣営コメントを含む総合的なコンディション。
血統 = 父・母父の距離・馬場・コース適性。実績の薄い馬（未勝利・新馬・初コース）ほど重み大。
ローテ = 前走からの間隔・休養明け・連戦疲労の評価。
前走補正 = 前走の結果（特に敗戦）をどれだけ「事故」として割引いて評価すべきか。不利・進路皆無・落鉄・極端ペース被害など。「度外視できる材料があるほど高得点」。

計算ロジック:

加重合計 = Σ(採点 × weight) / Σ(採点した軸の weight) ← 加重平均
  weight (G1): 近走0.20 / クラス0.15 / コース距離0.15 / 状態0.13 / 騎手0.08 / 馬場0.08 / 枠展開0.06 / 血統0.08 / ローテ0.05 / 度外視0.02
  weight (平場): 血統 0.10、状態 0.10 等で再配分
  weight (未勝利・新馬): 血統 0.25・状態 0.18・騎手 0.13 で再配分
↓ 補正（adjustments）を加算（補正履歴・evidence_ids 必須 = 隠れ補正禁止）
補正後 = 加重合計 + Σ(補正の差分)
情報量 = 軸ごとに集められた情報量（追切評価が複数あるか、過去走の本数、騎手データの蓄積など）の平均
  0/5＝そもそも採点できる材料がない 〜 5/5＝一次情報まで揃って確信を持って採点できる
↓
総合スコア = 補正後 × (情報量 / 5) ← 印選定に使う最終値
  同じ採点でも、材料が乏しい馬は控えめ評価になる仕組み（過信防止）

今回の学び

前走の直接対決の着差は、コース経験の欠如より重いアンズアメは前走・水無月Sでサンライズアムールに0.8秒先着していた。この直接対決の事実をtags_strongに書きながら、「盛岡初コース・輸送未経験・重賞初挑戦」という経験系の減点を優先して◯に留め、結果は1着。同一路線の2頭が同じレースに出てくる場合、直接対決の着差を最上位の判定材料に置き、コース初経験は「実績が拮抗しているときの決勝点」に格下げする運用へ改めたい。
『誰が逃げるか』は脚質タグの合算では決まらない☆チアフルヴォイスを『盛岡の地元逃げ馬・52kg』としてハナを主張できると読んだが、実際は先手を取れず7番手、代わりに◎サンライズアムールが単騎逃げに持ち込んだ。leg_derived（平均4角位置からの導出）は『前に行きたい馬』は拾えるが、『実際にハナを取れる馬』の優先順位までは決められない。テン3F実績・枠順・斤量・格の4点で逃げ争いの序列を明示する欄を予想側に設けたい。同日の浦和・ルーキーズサマーカップでも同型の外し方をしており、本日2レース連続の再現事故である。
印が的中しても配当が付かない構図を事前に見抜く◎◯▲△△☆の6頭中3頭で決着したが、3連単1,420円・3連複380円・馬連290円と配当は総じて安い。10頭立て・JRA勢と地方勢の力差が明確なダートグレードでは、印を当てても回収に結びつかない。予想段階で『印の的中期待は高いが妙味は薄い』と明示し、見送りまたは単勝・馬単の一点厚めといった券種選択に落とす判断欄が要る。
